💻 Meu Blog de Programação e Tecnologia

Bem-vindo ao meu blog! Este projeto foi criado para compartilhar conhecimentos, dicas de programação e curiosidades sobre tecnologia.

📚 Sobre o projeto

O blog apresenta conteúdos introdutórios sobre programação e Inteligência Artificial, com o objetivo de ajudar iniciantes a conhecer melhor o mundo da tecnologia.

📝 Conteúdos

- **Meu primeiro post:** apresentação do blog.
- **O que é programação?** conceitos básicos e linguagens de programação.
- **O que é inteligência artificial?** como a IA funciona e onde é utilizada.
- **Resumo final:** conclusão dos assuntos abordados.

🛠️ Tecnologias utilizadas

- HTML5
- CSS
- JavaScript 

🎯 Objetivo

Compartilhar conhecimento, incentivar o aprendizado e mostrar como a tecnologia pode transformar ideias em projetos reais.
